# Configuration

This directory contains configuration assets from the original OSINT_deepseek project and future FATHER profiles.

Current `high_technology_watchlist.yaml` is treated as **LEGACY/INPUT CANDIDATE** until reviewed against the new `ResearchTask` and collector contracts.

Configuration flow must eventually be:

```text
approved mission/profile requirement
        ↓
configuration schema
        ↓
validated config
        ↓
runtime component
        ↓
test evidence
```

Do not grow configuration keys before the corresponding requirement and consumer are approved.
