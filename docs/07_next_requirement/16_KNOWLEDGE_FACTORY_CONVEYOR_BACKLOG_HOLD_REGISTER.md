## Allowed exceptions

A HOLD item may temporarily enter WIP only when all are recorded:

1. direct P0 blocker ID;
2. exact expected output;
3. bounded time/tool budget;
4. acceptance test showing the blocker is removed;
5. automatic return to HOLD after the output is integrated.

No HOLD track may create a second architecture or duplicate registry/knowledge model.
