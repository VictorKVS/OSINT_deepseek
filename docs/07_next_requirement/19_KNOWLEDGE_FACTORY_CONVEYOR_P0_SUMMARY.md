# P0 Summary — Knowledge Factory Conveyor

**Single active objective:** build a reusable end-to-end conveyor that finds, acquires, preserves, compiles, extracts, relates, compares, reviews and packages knowledge with full provenance.

**All unrelated work:** HOLD.

**Critical path:**

```text
SourcePolicy
→ exact acquisition
→ immutable artifact/version
→ D0-D3 acceptance
→ structure/chunks
→ concepts/definitions/atomic rules
→ relations/applicability/version graph
→ conflicts/gaps
→ Analyst/Socrates
→ D15 KB-ready package
→ monitoring/reuse/regression
```

**First bottleneck:** exact D0-D3 acquisition with real bytes, MIME, size, SHA-256, version registry and append-only audit.

**Do not do now:** new standalone agents, new OSINT tools, speculative UI polish, RL/deep training, autonomous publication or parallel specialist pipelines.

**Success:** the second knowledge domain reuses the same conveyor rather than receiving a new bespoke implementation.
