## Operating rule

Every material research action must be reflected in the journal before it is promoted into a formal report. The journal records:

- query / source;
- exact result;
- evidence grade;
- what the result supports;
- what it does not support;
- next pivot;
- failure or access limitation when applicable.

Google Drive remains the editable formal-report workspace. GitHub is the versioned audit trail for methodology, search progress and redacted/publicly shareable research metadata.
