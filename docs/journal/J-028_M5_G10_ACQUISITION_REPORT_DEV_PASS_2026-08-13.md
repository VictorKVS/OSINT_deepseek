## Implemented

`father_osint/acquisition_report.py` now contains a deterministic `AcquisitionReport` contract and `DeterministicAcquisitionReportBuilder`.

The report preserves, without inventing missing values:

- ResearchRequest objective and questions;
- SearchPlan and EvidencePackage lineage;
- searched source scope;
- all source attempts, including failed/blocked attempts;
- explicit collection bounds supplied by execution layer;
- provenance/evidence/lead references;
- contradictions;
- counter-evidence status and retained refs when available;
- separate evidence-quality dimension summary without aggregate truth probability;
- coverage;
- requested versus achieved sufficiency;
- sufficiency reasons;
- unresolved gaps and limitations;
- recommended follow-up search;
- DecisionRecord lineage.

## Guardrails proved

1. Failed source attempts are not silently omitted.
2. Cross-case/request/SearchPlan lineage mismatch fails closed.
3. `requested_sufficiency` is never confused with `achieved_sufficiency`.
4. `INSUFFICIENT` can be transparently delivered to Analyst.
5. No synthetic confidence/truth probability is generated by the report layer.
6. The report is a projection of prior audited protocol objects; it does not create new factual evidence.
