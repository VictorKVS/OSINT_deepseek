# J-031 — BRAIN FIRST priority override

Date: 2026-08-16

## Decision

OSINT development priority is changed from source/tool expansion and immediate mechanical M5 closure to a brain-first sequence:

1. recognized intelligence/evidence-analysis methods research;
2. INTELLIGENCE_ANALYSIS_METHODS_KB;
3. versioned reasoning/sufficiency/conclusion provenance;
4. re-audit and A/B test G7–G10;
5. Telegram live calibration and M5 closure;
6. only then expand source/tool families.

## Reason

The current Telegram vertical is technically useful, but its non-calibrated policy logic must not be mistaken for expert methodology. The system must know how to evaluate information and justify conclusions before increasing collection capability.

## Guardrail

No current working algorithm is replaced merely because a different method is found. Research produces KEEP/MODIFY/REPLACE/EXPERIMENT/DEFER decisions backed by sources, review and regression tests.
