# 01. Видение и границы

## Цель

Создать официальный OSINT Case & Evidence Management System, который помогает:

- ставить и ограничивать задачу исследования;
- собирать законно доступные материалы;
- сохранять первичные данные и происхождение;
- отделять сообщения источников от установленных обстоятельств;
- строить граф связей и хронологию;
- сравнивать независимые аналитические мнения;
- выявлять противоречия, пробелы и альтернативные объяснения;
- формировать служебные справки;
- доказывать, кто, когда и из каких материалов получил вывод.

## Роли

| Роль | Ответственность |
|---|---|
| Постановщик | цель, полномочия, ограничения, результат |
| Составной аналитик | сбор, нормализация, первичные кандидаты |
| Главный аналитик | сопоставление, версия, выводы, качество доказательств |
| Red Team / Сократ | альтернативы, опровержения, противоречия |
| Правовой/данный контролёр | режим данных, ПДн, публикация, хранение |
| Руководитель | решение и резолюция |
| Администратор | политики, адаптеры, доступ, журналирование |
| Аудитор | воспроизводимость и полнота следа |

Высоковлияющий вывод требует независимой проверки.

## Типы дел

- `CORPORATE_DUE_DILIGENCE`
- `THREAT_INTELLIGENCE`
- `BRAND_PROTECTION`
- `SUPPLIER_RISK`
- `REGULATORY_INTELLIGENCE`
- `MEDIA_NARRATIVE_ANALYSIS`
- `AUTHORIZED_SECURITY_ASSESSMENT`
- `SYNTHETIC_TRAINING`

`AUTHORIZED_SECURITY_ASSESSMENT` требует отдельного письменного scope.

## Границы первого релиза

Входит: карточка дела; реестр источников и captures; сущности, отношения, claims и findings; зоопарк через реестр; disagreement-first review; audit; синтетический кейс; официальный отчёт; redacted export.

Не входит: скрытое получение данных; обход аутентификации; массовое профилирование без цели; свободное активное сканирование; эксплуатация; credential attacks; phishing delivery; автоматическая публикация; LLM→FACT.

## Критерий ценности

Руководитель открывает каждый вывод по цепочке:

```text
решение → рекомендация → риск → finding → claims/opinions
→ source IDs → captures → originals + hashes
```

и отдельно видит: установлено / вероятно / версия / противоречия / пробелы / предлагаемое действие.
