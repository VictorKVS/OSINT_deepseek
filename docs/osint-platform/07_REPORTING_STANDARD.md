# 07. Стандарт официальной отчётности

## Пакет дела

1. Основная служебная аналитическая справка.
2. Карточка организации.
3. Справки по материально связанным лицам.
4. Хронология.
5. Граф связей.
6. Профильные приложения.
7. Реестр источников.
8. Реестр противоречий/пробелов.
9. Red Team-заключение.
10. Матрица рисков.
11. Проект решения/резолюции.
12. Export manifest и карта версий.

## Основная справка

Гриф/класс; адресат; основание/цель; объект/период; ограничения; краткий управленческий вывод; установленные обстоятельства; вероятные обстоятельства; неподтверждённые версии; противоречия; риски; рекомендации; проект резолюции; приложения; исполнитель/reviewer/version/hash.

## Формулировки

Допустимо: «Установлено…», «Согласно официальному документу…», «Источник X утверждает…», «Имеются признаки…», «Высоко вероятно при ограничениях…», «Не подтверждено…», «В проверенных источниках сведения не выявлены…».

Без компетентного основания нельзя: «преступник», «соучастник», «фирма-прокладка», «виновен», «доказанная схема» и иные обвинительные/процессуальные статусы.

```text
вывод → supporting claims → source cards → capture metadata → original
```

Дизайн строгий, печатный, со стабильной пагинацией. Exploratory animation не переносится в PDF/DOCX.

## Версии

`case_id`, `document_id`, revision, generated_at, author/reviewer, access_class, source snapshot, SHA-256, Git commit, Drive revision, supersedes/superseded_by.
