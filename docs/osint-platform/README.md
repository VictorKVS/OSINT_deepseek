# FATHER OSINT Platform — Architecture Baseline v0.1

**Статус:** DRAFT / CONTRACT-ONLY  
**Дата baseline:** 2026-09-01  
**Связанные требования:** GitHub Issues #20 и #21  
**Ограничение:** замороженный DEV v1 не изменяется; пакет не вводит production-код и не разрешает активное воздействие на внешние системы.

## Назначение

Baseline определяет следующий слой `OSINT_deepseek`: официальное ведение дел, доказательственную трассировку, управляемый аналитический «зоопарк», безопасное подключение инструментов, формирование служебных справок и контролируемый экспорт.

```text
SOURCE → SOURCE_CAPTURE → CLAIM → ENTITY / RELATION
       → INDEPENDENT ANALYST OPINIONS
       → CONSENSUS / DISAGREEMENT
       → FACT | INFERENCE | HYPOTHESIS
       → RISK → RECOMMENDATION / DECISION → REPORT / EXPORT
```

## Неподвижные принципы

1. Коллектор возвращает материал, а не истину.
2. Оригинал и его хеш важнее любой сводки.
3. `CLAIM`, `FACT`, `INFERENCE` и `HYPOTHESIS` — разные объекты.
4. Ни одна LLM, модель, алгоритм или инструмент не создаёт `FACT` напрямую.
5. Каждый существенный вывод открывается до источника и сохранённой копии.
6. Публичный GitHub хранит код, схемы, методику, синтетические/редактированные примеры, хеши и реестры — не сырые чувствительные доказательства.
7. Инструмент не становится разрешённым только потому, что установлен в Kali.
8. Официальный экспорт проходит правовые, доказательственные и редакционные ворота.
9. Все ручные и автоматические изменения журналируются.
10. DEV v1 остаётся контрольной линией и не меняется этим baseline.

## Не входит

- изменение `father_osint`, collectors, storage, pipeline или transports;
- сетевой сбор и реальные материалы расследований;
- Neo4j/PostgreSQL/LLM runtime;
- unrestricted shell;
- автономная атрибуция или юридическая оценка конкретных лиц;
- автоматическая публикация.

## Следующий разрешаемый шаг после review

```text
синтетическое дело → источник → capture + SHA-256 → claim
→ entity/relation → independent opinions → consensus/dissent
→ reviewed finding → official report → redacted export
```
