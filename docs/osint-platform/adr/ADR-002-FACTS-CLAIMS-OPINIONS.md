# ADR-002 — Разделение claims, opinions и facts
**Статус:** Proposed · **Дата:** 2026-09-01

## Контекст
Источник ошибается, модель галлюцинирует, аналитик интерпретирует. Единое поле «вывод» уничтожает статус.

## Решение
Отдельно хранить `CLAIM`, `ANALYSIS_OPINION`, `CONSENSUS`, `FINDING`. Только человек по политике переводит кандидат в FACT.

## Последствия
Объяснимость и Red Team; больше объектов и workflow states.
