# ADR-003 — Управляемый аналитический зоопарк
**Статус:** Proposed · **Дата:** 2026-09-01

## Контекст
Одна модель не покрывает текст, граф, право, медиа и challenge. Majority voting усиливает коррелированные ошибки.

## Решение
Registry-driven ensemble: blind first pass, разные families, contrarian, immutable opinions, consensus+dissent, data boundary, calibration, human gate.

## Отвергнуто
Одна универсальная модель; автономный judge без evidence; голоса копий одной family; restricted data в remote provider по умолчанию.

## Последствия
Устойчивость и специализация; выше стоимость, latency и сложность.
