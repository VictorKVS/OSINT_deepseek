## Gates added or reinforced

1. `HABR_DUPLICATE_SAME_ACT != TWO_NORMATIVE_RECORDS` — duplicate section placement must map to one canonical act identity.
2. `HABR_ACT_TYPE_LABEL != CANONICAL_ACT_TYPE` where number/date/title identify the same act; preserve the source label as conflict metadata, not as a second act.
3. `SAME_NUMBER_DIFFERENT_YEAR_SEARCH_COLLISION` — number-only search cannot establish identity.
4. `RED_EDITION_DATE != ALL_AMENDMENTS_EFFECTIVE_ON_THAT_DATE` — a consolidated-card date can coexist with amendments having future effective dates.
5. `CURRENT_EFFECTIVE_BODY + ENACTED_FUTURE_BODY` must be stored separately where tomorrow's amendment is already signed/published.
6. `MENTION_OR_STUDY_TABLE != FULL_TEXT` even when number/date/title are correct.
7. `PRIMARY_PUBLICATION_OF_AMENDING_ACT != PRIMARY_CONSOLIDATED_CURRENT_CARD` — both are separate verification fields.
8. `NO_AMENDMENT_FOUND != PRIMARY_CURRENT_STATUS_CONFIRMED`.
