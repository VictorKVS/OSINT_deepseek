## Gate discipline

1. A GitHub filename equal to a `publication.pravo.gov.ru` publication ID is not a normative body unless the file is actually present and its internal number/date/title and completeness are verified.
2. Current-edition status is tracked separately from GitHub-copy completeness. Old GitHub text can be complete yet legally stale.
3. Draft amendments are stored in a separate lifecycle state and are never merged into the effective current body until a final signed/published act is confirmed.
4. Official publication index metadata is accepted as primary publication evidence; a failed direct document-card fetch is retained as a separate retrieval blocker rather than erasing the publication evidence.
