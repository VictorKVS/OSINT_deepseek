## Gate discipline

1. GitHub search hits are promoted only after internal number/date/title identity checks; generic token/corpus noise is not stored as a candidate.
2. Official publication pointer, direct body fetch and current consolidated legal status are independent fields.
3. A PDF hosted on an agency domain can still be a secondary copy if the file itself identifies a third-party legal system as its source.
4. Draft amendments remain separate lifecycle objects until a final signed/published act is found.
5. Completeness for multi-appendix agency PDn orders requires the complete order plus every approved appendix; one appendix alone is not `FULL_TEXT`.
