## Manual save convention

1. Save the official file to `_MANUAL_OFFICIAL_INBOX`.
2. File name: `<document_id>.pdf` (or `.html/.docx/...` if that is the official artifact).
3. Preferably save a second tiny text file `<document_id>.source.txt` with the exact official URL copied from the browser.
4. Run `IMPORT_SECURITY_OFFICIAL_MANUAL_INBOX.cmd` once after the batch is downloaded.
5. The importer keeps `document_identity_confirmed=false`, `currentness_verified=false`, `legal_truth_eligible=false` until review.
